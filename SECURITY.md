# Security policy

Please **do not open a public issue** for security problems. Use GitHub's private vulnerability reporting ("Security" tab, then "Report a vulnerability"), or email support@spare.cool. Include the affected file, steps to reproduce and the impact you expect.

We aim to acknowledge reports within 7 days.

In scope: the launcher UI code in this repository and the Spare io iPhone app (closed source; report privately all the same). Out of scope: RayNeo's own firmware, apps and cloud services.
