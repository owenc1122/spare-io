# 虚构示例

以下转录完全虚构。下方成稿来自最终版写作规则的一次两级生成，方便对照选择了什么、略去了什么。

## 输入

```text
#1 [09:10:00] 我：预览发现第二页表格被裁掉了。缩小的话字又太小，先查一下字体和列宽。
#2 [09:15:00] 同事：别缩字，保留原字号，下午一起看导出的两页。
#3 [12:00:00] 电视外放：剧情里有人说“搜索天气、打开计算器”。
#4 [14:20:00] 我：查明白了，是字体被替换，把分页挤乱了。换回字体，锁定列宽就好了。
#5 [14:25:00] 我：重新导出看了，两页都完整，字没有缩小，这版可以交付。
#6 [16:10:00] 我：刚试会重复表头，翻下一页也能看见列名，以后长表就这么弄。
#7 [18:10:00] 我：电池健康84%，续保650元，单换电池480元，差170元，还能考虑30天。
#8 [18:12:00] 我：今天先不付，观察实际续航再决定，不想光看健康数字就换。
#9 [19:30:00] 我：帮我拿一下水，声音小一点。
```

## 每日回顾实际样稿

上午预览表格时发现第二页被裁掉，直接缩小又会让字太小，便先检查字体和列宽。同事建议保留原字号，下午一起检查导出的两页。下午查明是字体被替换后挤乱了分页，换回字体并锁定列宽就恢复了正常。重新导出后逐页检查，两页都完整，字也没缩小，确认这版可以交付。下午还试会了重复表头，翻到下一页也能看见列名，以后处理长表就用这个办法。

傍晚考虑了电池的事：健康度84%，续保650元，单换电池480元，相差170元，还有30天可以考虑。今天先不付钱，想观察实际续航后再决定，不想只看健康数字就换电池。

## 对照

- 字体问题保留“发现问题—拒绝缩字—查明原因—复核完成”的变化，不把讨论直接写成完成。
- 重复表头是短暂但清楚的学习，保留；电视剧情和拿水、调音量略去。
- 电池比较保留 84%、650 元、480 元、170 元差价及 30 天考虑期；“可以交付”和“今天先不付”保持各自状态。
- 分块结果把第 3、9 行列入 `irrelevant`。这里的第 9 行表示低信息量过滤，不表示它来自媒体。
- 列表字段照常填写。下面是按新规则手写的期望值（未经模型重放），正文已经写到的事才进列表：

```json
{"highlights":["查明表格被裁是字体替换导致，换回字体并锁定列宽后可以交付","学会长表重复表头","电池先不付，观察续航再决定"],
 "todos":[],
 "decisions":["表格保留原字号，换回字体并锁定列宽后这版交付","电池今天先不付，观察实际续航后再决定"],
 "people":["同事（一起排查表格导出）"],
 "follow_ups":["电池续保650元还是单换电池480元，30天内决定"]}
```

  分块的 `key_info` 对应保留电池健康 84%、续保 650 元、单换电池 480 元、30 天考虑期；“下午一起看导出的两页”当天已完成，不进 `todos`。
